# AI House Price Predictor

A futuristic Hacker-style AI web app that predicts house prices using Machine Learning.

## Features
- Cyberpunk / Hacker UI
- Real-time ML predictions
- Streamlit interactive dashboard
- California Housing Dataset

## ML Details
- Algorithm: Linear Regression
- Scaling: StandardScaler
- Metric: R² Score

## Tech Stack
- Python
- Streamlit
- Scikit-learn
- NumPy, Pandas

## Run Locally

```bash
pip install -r requirements.txt
python train.py
streamlit run app.py
```
